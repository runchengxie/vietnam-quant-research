# 越南日频信号验证约定

本项目可以借鉴既有研究工作区的验证骨架，但不直接移植 A 股的股票池、行业分类、因子方向或参数。越南市场的停牌、涨跌停、流动性分布和价格语义仍需用本地证据重新确认。

## 形成与交易

- 形成日只能使用当日收盘时已经可得的数据。
- 默认从下一交易日开始持有，避免把形成日收盘价同时当作可成交价。
- 只使用 `research_eligible=true` 的价格记录计算收益率。
- `tradable` 需要有效价格和正成交量。停牌、零成交、涨跌停和退市处理必须保留为显式状态，不得静默填充或把资金重新分配给其他股票。

## 数据可得性

- 公司行动和基本面字段按可得时间对齐，而不是按报告期末日期回填。
- VCI/KBS 的 raw/adjusted 语义未独立确认前，长周期动量和反转只能作为诊断结果，不能作为已验证信号。
- HNX 交易所锚点、SSI 的 raw/adjusted 字段和事件表都属于证据层，不能直接覆盖供应商原始记录。

## 最小验证顺序

1. 先报告覆盖率、缺失、异常 OHLC、零成交、停牌和跨源差异。
2. 对日频动量、反转、换手率/流动性、规模、波动率和涨跌停行为做截面分组，先看样本量和单调性。
3. 固定股票池和参数后，再做滚动样本外检验。训练或参数选择不得读取最终样本外区间。
4. 对标签跨界的模型实验，按标签持有期配置 purge 或 embargo；简单日频排序因子则重点检查形成日错位和价格可得性。
5. 在毛收益之外，同时报告换手率、交易成本、流动性参与率、不可成交比例和净收益。至少做一个成本压力场景。

## 第一版结果表

每个信号至少记录：样本区间、股票池定义、有效股票数、形成日数量、分组收益、IC 或排序单调性、换手率、成本假设、毛/净收益、最大回撤、样本外区间和已知缺口。

只有当质量门槛通过、价格语义被独立确认且基础信号经过成本和样本外检验后，`factor_ready` 才能进入下一阶段。远端项目的 15 因子体系、A 股行业中性化和具体流动性阈值不属于本项目当前默认配置。
