# 越南市场量化研究资料库设计说明

**日期：** 2026-08-27  
**状态：** 已确认，首版进入实施

## 目标

建立一个公开的、以中文为主的越南股票市场量化研究资料库。首版聚焦数据获取思路、渠道比较、价格与授权边界，以及后续数据库建设路线；暂不加入数据采集代码、交易逻辑或任何凭证。

## 使用场景

读者应能够通过仓库文档回答以下问题：

1. 越南股票市场有哪些可用的数据渠道？
2. 每个渠道覆盖哪些市场和字段，适合日频、分钟、实时还是基本面研究？
3. 公开价格大约是多少，哪些项目需要询价或账户审批？
4. 如果先做低成本研究，应该如何组合数据源？
5. 建库时如何处理 HOSE、HNX、UPCoM、衍生品、转板、退市、复权和外资额度等问题？

## 设计原则

- **来源优先：** 优先引用交易所、VSDC、券商、数据供应商的官方页面；二手资料只用于线索。
- **报价分级：** 明确区分公开标价、历史观察价、免费公开数据、账户/审批条件、询价项目，不把询价写成确定价格。
- **时间戳：** 价格、汇率和服务条款必须写明核验日期；页面会变动，后续更新时保留更新时间。
- **币种透明：** 主表保留 VND 原价，同时使用同一基准汇率换算人民币；人民币结果只作为预算估算，不代表支付结算价。
- **研究与生产分离：** vnstock 等聚合工具适合原型和交叉核验，生产库需要保留原始响应、来源、抓取时间和授权记录。
- **公开仓库安全：** 不提交 API key、secret、token、账号信息、商业数据文件或受许可限制的原始数据。

## 数据源分层

### 1. 免费/低成本研究层

- vnstock Community：快速原型、日线和基础财务数据。
- VSDC 公开页面：外资持股上限、剩余可买数量、证券状态、部分证券主数据与事件。
- 交易所公开页面：市场概览、日度数据、发行人披露和统计信息。

### 2. 个人研究与券商 API 层

- SSI FastConnect Data：证券列表、指数、日线 OHLCV、盘中 OHLCV、实时数据和 WebSocket；需要 SSI 账户、申请批准和遵守 API 条款。
- 其他本地券商或聚合 API：作为待核验候选，不在首版中对未确认的具体价格作承诺。

### 3. 商业标准化数据层

- FiinPro-X：实时/历史行情、财报、估值指标、公司资料、所有权、公司行动、宏观和研究工具；适合需要标准化和历史整理的基本面研究。

### 4. 机构级行情 Feed 层

- HOSE、HNX 官方 Feed：实时、延迟、EOD、深度行情或交易所消息流；通常涉及连接、数据包、终端/用户和再分发授权。
- ICE、Bloomberg、LSEG/Refinitiv：适用于机构级跨市场、Tick/Level 2 或正式许可场景，价格通常询价。

## 文档之间的边界

- `data-sources-overview.md`：渠道、数据类型、市场覆盖、访问方式、适用研究场景。
- `pricing-and-costs.md`：VND 原价、人民币估算、汇率、VAT/连接费/授权费提示和报价置信度。
- `recommended-data-stack.md`：按预算和研究阶段给出数据组合，并提出 raw/normalized/derived 三层架构。
- `data-quality-and-risks.md`：point-in-time、复权、转板、退市、停牌、交易时区、外资额度和许可证风险。

## 非目标

- 首版不实现爬虫、API client、定时任务或数据库 schema migration。
- 首版不提供投资建议、收益承诺或可直接用于交易的策略。
- 首版不复制商业数据商的原始数据，不绕过登录、验证码或访问控制。
- 首版不把所有供应商的价格写成永久有效；价格变动应通过更新日期和来源链接追踪。

## 验收标准

- 仓库是公开 GitHub 仓库，默认分支为 `main`。
- `README.md` 能说明项目目标、范围、文档入口和安全边界。
- 四篇文档均已创建，包含可点击来源链接、价格/覆盖范围说明和明确的不确定性标注。
- 人民币价格换算使用统一公式，并列出汇率日期与费用未含项。
- `git status` 干净，Markdown 文件可被正常读取，仓库中无凭证和数据文件。
